## Test-file inspection

All four Python test files and all four pre-existing Node test scripts were read. The tests contain behavior assertions, not unconditional passing placeholders. The strategy/policy test expands to 16 cases, each exercising four scenario fixtures. Corruption tests alter actual generated plans and independently reject them. Ledger tests check the physical conservation equation, explicit recovery, repeated cumulative reports and invalid transitions. Operation/revision tests preserve historical reports and reject stale or malformed actions.

Gaps found in the original suite were addressed with 18 independent validator corruption cases, potable-confirmation blocking, a delayed-request race regression, repeated revision-cache checking, corrupt storage preservation, invalid HTTP bodies and export content/approval tests. The delayed-request regression was observed failing against the original implementation (200 instead of 409), then passing after the fix.

The HTTP ordering test replaces only the domain worker to isolate request concurrency; the separate API integration uses the real Python worker. Export tests use a small document/download substitute to inspect generated Blob contents, not to claim a browser saved a file. No blanket statement of complete path/branch coverage is made.

## Defects corrected during this audit

1. **Stale delayed writes:** operation versions were captured before the request body arrived. Another request could commit while the first was still receiving, and the first could overwrite it. Read/version-check now happens after body receipt; regression preserves the newer update and returns 409 for the stale request.
2. **Approval label crossed strategies:** every strategy uses the same input hash. Checking that hash alone incorrectly labelled other strategies approved. Export approval now requires the approved strategy, input hash and route contents to match.
3. **Revision job cache growth:** revision jobs bypassed the planning cache's 50-record limit. Revision admission now evicts old job/input records and expired revision-request entries; 55 revisions retain 50 jobs.
4. **Malformed planning HTTP bodies:** `null` could cause a server error. Non-object/malformed JSON now returns a readable 400; real API integration checks it.
5. **Malformed persisted envelope:** storage now rejects null/array envelopes, array maps and unsupported versions while preserving the original file. Corrupt JSON is also preserved rather than reset.
6. **Premature Blob cleanup:** downloads used an unattached link and immediately released the URL. Shared download handling attaches/removes the link and defers URL release, including evidence JSON. This addresses a browser-consumption risk, but the in-app download still did not return a file, so saving remains an open acceptance item.

Changed code: `scripts/local-api.mjs`, `scripts/local-operations.mjs`, `scripts/local-storage.mjs`, `apps/web/src/exports.ts`, `apps/web/src/App.tsx`. Expanded/new tests: `services/planner/tests/test_planner.py`, `scripts/test-local-api.mjs`, `scripts/test-storage.mjs`, `scripts/test-local-operations.mjs`, `scripts/test-exports.mjs`.
