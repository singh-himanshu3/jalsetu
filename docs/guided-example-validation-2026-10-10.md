## Milestone 1: guided example

Try the example opens a short welcome with four visible steps. Start guided example loads the existing sample. The guide advances from explicit operating rules to a checked plan, approval, loading and the first positive delivery report. Loading does not complete the guide. Its next action takes the user to the relevant setup, approval or report section. Completing the practice path offers resource comparison.

Explore without the guide, Hide guide, Show my example guide and Escape dismissal are supported. Starting a fresh sample clears the selected operation, not saved approvals/reports. Opening a saved project or operation ends the fresh-example guidance. No JSON, diagnostic stages, hashes or automatic approvals/reports were added to the product.
