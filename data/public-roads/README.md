# Frozen public-road research snapshot

`north-delhi-osrm.json` preserves one actual OSRM public-car table response for nine **example** North Delhi coordinates. The request, response, snapped endpoints, retrieval time and integrity hashes are retained. The map date was not provided. No real water requests, inventory, confirmed facilities, site permissions or observed deliveries are encoded here.

Routing estimates are derived through [OSRM](https://project-osrm.org/) using the FOSSGIS public car service. Collection used a valid identifying User-Agent and a single request, within the [provider usage policy](https://routing.openstreetmap.de/about.html). Comparisons replay the saved response without provider requests. There is no continuous scraping, automatic update, service guarantee, traffic feed or tanker-specific accessibility model.
